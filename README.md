# jeni 試験版

すべてをカードで表し、カードを持つ・投げ銭する・使うことで、お金に結びつかない jeni がめぐる仕組みの試験版です。

- 元の構想と最初の試作（app30）は参考にするだけで、ここで一から簡素に作り直します
- 相互レビューで実際に動いている仕組み（共通のアカウント・パスキー・運営なしで同じ結果になる決まり）を土台にします
- 一度に多くを変えず、画面を見ながら一つずつ進めます

## いまの段階

- **最初の画面の試作**（`proto/home.html`）：プロフィールカードのアイコンがメニューを兼ね、押すとその種類のカードだけが流れる。カードはすべて 1.586:1。中身は見本で、jeni は動きません

まだ決めていること：配る量と単位、入口（頼む・作る）の整理、相互レビューとのつなぎ方。
